# FAVEST

내 계좌를 점검하고, 내 조건(예산·투자 성향·투자 기간·관심 업종)에 맞는 종목을 근거와 함께 추천하는 프로토타입입니다. 새움소프트 미니 과제로 만들었습니다.

- 배포: https://favest.vercel.app
- 과거 수치를 정리한 참고 정보이며 투자 권유가 아닙니다. 주가 전망이나 매수 권유 문구는 쓰지 않습니다.

## 주요 기능

- 내 계좌 점검: 평가금액·손익·예수금, 업종 비중, 보유 종목별 주의 문구, 보완할 추천 업종
- 종목 추천: 성향 5단계 × 투자 기간 3단계의 룰 기반 점수, 근거 문장, 예산 배분, 추가 투자 후 업종 비중
- 종목 탐색·관심 종목, 기간별 차트, 주의 알림
- 뉴스 요약: Google 뉴스 RSS 기사 제목을 Gemini(3.5 Flash-Lite)가 3줄로 요약
- 입력 방식: 7문항 성향 진단, 직접 설정, 거래내역 CSV, 증권사 계좌 연결(데모)

## 기술

- Vite + React + TypeScript, Vercel 배포(서버리스 함수는 `api/news.ts` 하나)
- 시세: FinanceDataReader로 받은 43개 종목, 125거래일 스냅샷(`src/data/stocks.json`, 수집 스크립트 `scripts/fetch_data.py`)
- 계산과 계정·조건 저장은 모두 브라우저(localStorage)에서 처리합니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 타입 검사와 빌드
```

뉴스 요약을 쓰려면 `GEMINI_API_KEY` 환경변수가 필요합니다(`.env.example` 참고). 키는 저장소에 넣지 않고 Vercel 프로젝트 설정에만 둡니다. 키가 없으면 검색 링크로 대체됩니다.

## 구조

```
api/news.ts            뉴스 수집·요약 서버리스 함수
src/lib/engine.ts      점수 계산과 추천(성향·기간 가중치, 필터, 분산)
src/lib/sectorPick.ts  보완할 업종 선택(상위 점수 종목이 몰린 업종)
src/lib/alerts.ts      주의 알림 규칙
src/components/        화면(첫 화면, 내 계좌, 추천, 팝업 등)
docs/                  보고서, 검증 자료, 발표자료 원본
```

## 문서

- [보고서](docs/report.md): 기획 의도, 선별 기준, 점수의 근거와 검증, 한계
- [검증](docs/validation/): 점수 요인별 순위 상관을 계산하는 스크립트와 결과(`node docs/validation/backtest.cjs`)
- [발표자료 원본](docs/presentation/): 슬라이드 HTML 원본. 이미지는 온라인 발표 도구의 자산을 참조하므로 이 폴더만으로는 완전하게 보이지 않을 수 있습니다.

## 한계
